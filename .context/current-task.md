## 已实现

- `proxy/kilo.rs` 的 `extract_proxy` 读取 Provider 的 `settings_config.options.proxy`，使用 `as_str → trim → 过滤空串`；无值直连，有值直接交给网络库，不增加后端业务格式校验。
- `build_http_client` 独立构建 Kilo 客户端，先 `.no_proxy()`，有值再加入 `reqwest::Proxy::all`。不继承全局、系统和环境代理，本机目标也不绕过显式代理，失败不回退直连。
- 客户端保留连接超时、连接池、keepalive、禁用自动解压和重定向；无覆盖流式响应的总超时，后续转发可复用。
- `reachability_client` 封装配置读取和构造错误转换；`reachability_base_url` 读取检测目标，不依赖完整 Provider parser。
- `services/stream_check.rs` 的 `check_once` 仅为 Kilo 调用专用入口，其他 AppType 保持 `get_for_url`；构造失败进入原有检测结果展示。
- 原有 GET、任意 HTTP 响应视为可达、单次请求超时、计时、降级、重试与 baseURL override 逻辑保留。
